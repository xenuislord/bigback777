6. Validation: `npm run check`, `npm test`, and `npm run build`. Use `npm run test:e2e` for desktop/iPhone-sized Chromium flows (isolated temporary DBs, ports 4311 and 4313); `/usr/bin/chromium` is selected when present, otherwise install Playwright Chromium through the allowed official download hosts. `npm run test:runtime` checks the server bundle inside Electron's Node runtime using a temporary database on port 4312. These checks need local socket/browser capability. Do not disable TLS/artifact verification.

Defaults work without AI and never fabricate live prices. Use app Settings for user credentials; never ask for secret values in chat.
8. The iPhone needs the host Mac, private Tailscale Serve HTTPS, and the setup in `docs/IPHONE.md`. A cloud process or saved HTTPS address does not prove Mac/iPhone connectivity. Do not create onboarding web-preview links to loopback addresses. Native Mac packaging/Keychain require testing on an actual Mac.
